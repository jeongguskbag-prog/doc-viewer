# 문서 통합 뷰어 — 보안 검토 자료

기관의 보안성 검토·도입 검토 담당자를 위한 자료입니다. 앱이 **어디와 통신하는지, 무엇을 어디에 저장하는지, 어떤 권한을 쓰는지**를 소스 코드 기준으로 정리했습니다.

- 기준 버전: 2.2 (안드로이드 versionCode 13, 윈도우 2.2.0)
- 소스: 이 저장소 전체 (화면: `android/app/src/main/assets/public`, 안드로이드: `android/app/src/main/java`, 윈도우: `desktop/src-tauri`)

---

## 1. 배포판 구성

| 배포판 | 파일 | 대상 |
|---|---|---|
| 일반판 (안드로이드) | `DocumentViewer.apk` | 일반 사용자 |
| 기관용 망분리판 (안드로이드) | `DocumentViewer-Airgap.apk` | 망분리 환경 |
| 일반판 (윈도우) | `DocumentViewer-Setup.exe`, `DocumentViewer-Portable.zip` | 일반 PC |
| 기관용 망분리판 (윈도우) | `DocumentViewer-Airgap-Setup.exe`, `DocumentViewer-Airgap-Portable.zip` | 망분리 PC |

일반판과 망분리판은 **같은 소스**에서 빌드하며, 차이는 `config.js` 한 줄(`airgap`, `airgapLocked`)뿐입니다 (`scripts/write-config.js`). 망분리판은 망분리 모드가 **항상 켜져 있고 사용자가 끌 수 없습니다.**

---

## 2. 외부 통신

### 2.1 앱이 스스로 하는 통신

| 기능 | 대상 | 보내는 내용 | 일반판 | 망분리판 |
|---|---|---|---|---|
| 번역 (기본) | `api.mymemory.translated.net` | 번역할 **문서 글자** (파일은 보내지 않음) | 사용자가 번역을 고를 때만, 처음 1회 동의 후 | **없음** (기능 숨김 + 차단) |
| 번역 (API 키 설정 시) | `translation.googleapis.com` | 번역할 문서 글자, 사용자가 넣은 API 키 | 위와 같음 | **없음** |

그 밖의 통신은 **없습니다.**

- 광고, 사용 통계·분석, 오류 보고, 자동 업데이트 확인 **없음**
- 문서를 여는 라이브러리(PDF·워드·엑셀·한글·파워포인트)와 한글 PDF 글꼴 정보(CMap)는 **모두 앱 안에 포함** — 인터넷에서 내려받지 않음
- 마크다운 문서 안의 외부 이미지는 자동으로 불러오지 않고 주소만 표시

### 2.2 사용자가 직접 하는 동작 (앱 밖으로 넘김)

| 동작 | 처리 |
|---|---|
| 문서 안의 링크를 누름 | 기기의 기본 브라우저/메일/전화 앱을 실행 (`http`, `https`, `mailto`, `tel` 만 허용, 그 외 주소 형식은 차단) |
| 내보내기 → 이메일 / 팩스 / 공유 | 사용자가 고른 메일·팩스·공유 앱으로 파일을 넘김. 전송은 그 앱이 함 |

이 동작들은 망분리판에서도 막지 않습니다(사용자가 명시적으로 누른 경우만 해당). 기관 정책상 필요하면 막는 옵션을 추가할 수 있습니다.

### 2.3 망분리 모드의 차단 방식 (`airgap.js`)

망분리 모드에서는 화면이 뜨기 전에 다음을 적용합니다.

1. **브라우저 보안 정책(CSP)**: 연결·이미지·글꼴·미디어를 앱 자신(`self`), `blob:`, `data:` 로만 제한, 폼 전송 금지
2. **요청 함수 차단**: `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `sendBeacon` 의 외부 주소 요청을 거부
3. **화면**: 번역 버튼·번역 엔진 설정 숨김, 상단에 "🔒 망분리" 표시

윈도우판의 앱 내부 통신 채널(`ipc:`, `ipc.localhost`)은 같은 PC 안의 통신이라 허용합니다.

### 2.4 윈도우판 참고 사항

- 화면 표시에 Windows 의 **Microsoft Edge WebView2 런타임**을 씁니다. Windows 11 과 최신 Windows 10 에는 기본으로 들어 있습니다.
- **일반판 설치 파일**은 WebView2 가 없는 PC 에서 설치 중에 Microsoft 에서 WebView2 를 내려받습니다.
- **망분리판 설치 파일**은 이 단계를 건너뜁니다. WebView2 가 없는 망분리 PC 에는 Microsoft 의 WebView2 오프라인 설치 파일을 먼저 설치해야 합니다.
- WebView2 런타임 자체의 업데이트는 Windows/Edge 업데이트 정책을 따르며, 이 앱의 통신이 아닙니다.
- 앱 본체(Rust 코드, `desktop/src-tauri/src/lib.rs`)에는 네트워크 코드가 없습니다.

## 3. 권한

### 안드로이드 (`AndroidManifest.xml`)

| 권한 | 용도 | 비고 |
|---|---|---|
| `INTERNET` | 번역 (일반판) | 망분리판도 권한은 선언되어 있으나 앱 안에서 모든 외부 요청을 차단 |
| `CAMERA` | QR·바코드 카메라 스캔 | 사용자가 스캔을 누를 때 안드로이드가 허용 여부를 물음. 영상은 기기 안에서만 처리, 저장·전송하지 않음 |

- 저장소 전체 접근 권한(`MANAGE_EXTERNAL_STORAGE`, `READ_EXTERNAL_STORAGE`)을 **쓰지 않습니다.** 파일은 사용자가 고르거나 다른 앱에서 넘겨준 것만 엽니다.
- 위치, 연락처, 마이크, 전화 권한 없음

### 윈도우

- **관리자 권한 없이** 현재 사용자 계정에 설치 (`%LOCALAPPDATA%`)
- 웹 화면에는 파일 시스템·셸 권한을 주지 않음 (`capabilities/default.json` 은 기본 이벤트 권한만). 파일 저장은 Rust 쪽에서 "다른 이름으로 저장" 창으로 사용자가 고른 위치에만 씀
- 외부 주소 열기는 `http`, `https`, `mailto`, `tel` 만 허용

## 4. 저장하는 데이터

### 4.1 문서 파일

| 상황 | 저장 위치 | 지워지는 시점 |
|---|---|---|
| 앱에서 파일 열기 | 저장하지 않음 (메모리에서만 처리) | 앱 종료 시 |
| 다른 앱에서 "열기/공유"로 받은 파일 (안드로이드) | 앱 전용 캐시 `cache/opened/` | 다음 앱 실행 시 |
| 공유·이메일·팩스로 보낼 파일 (안드로이드) | 앱 전용 캐시 `cache/share/` | 다음 공유 시 |
| 내보내기 → 저장 | 안드로이드: 다운로드 폴더 (Android 9 이하는 사용자가 고른 위치) / 윈도우: 사용자가 고른 위치 | 사용자가 지울 때까지 |

열어 본 문서 목록은 저장하지 않습니다 (앱을 닫으면 사라짐).

### 4.2 설정값 (앱 전용 저장소, localStorage)

| 키 | 내용 |
|---|---|
| `viewer.lang` | 화면 언어 |
| `viewer.airgap` | 망분리 모드 켜짐/꺼짐 (일반판만) |
| `viewer.trConsent` | 번역 전송 동의 여부 |
| `viewer.trKey` | Google 번역 API 키 (사용자가 넣은 경우) — **암호화하지 않고 저장** |
| `viewer.mailTo` | 마지막으로 쓴 받는 사람 이메일 |
| `viewer.faxNo`, `viewer.faxWay`, `viewer.faxDomain` | 마지막으로 쓴 팩스 번호·방식·서비스 주소 |

- 윈도우판의 저장 위치: `%LOCALAPPDATA%\com.docviewer.desktop\` (망분리판은 `com.docviewer.desktop.airgap`)
- 앱 삭제 시 함께 지워집니다.

## 5. 문서 처리의 안전장치

- 문서에서 만든 화면(HTML)은 모두 **DOMPurify** 로 정리한 뒤 표시 (스크립트 실행 차단)
- 문서 안 링크는 `http`, `https`, `mailto`, `tel` 만 열림
- 다른 앱에서 받는 파일은 200MB 초과 시 거부, 파일 이름의 경로 문자 제거
- 암호가 걸린 HWP/HWPX 는 열지 않고 안내만 표시

## 7. 직접 확인하는 방법 (망분리판)

1. **차단 확인**: 망분리판을 인터넷이 되는 PC/폰에 설치하고, 방화벽·프록시 로그(또는 Fiddler 등)를 켠 채로 PDF·한글·엑셀·파워포인트를 열고 내보내기·인쇄를 해 봅니다. 앱에서 나가는 연결이 없어야 합니다.
2. **오프라인 동작 확인**: 네트워크를 끊은 상태(비행기 모드, 랜선 분리)에서 같은 작업을 해 봅니다. 모두 정상 동작해야 합니다.
3. **설정 확인**: ⚙ 설정에서 "망분리 모드"가 켜져 있고 끌 수 없는지, 화면 위에 "🔒 망분리"가 보이는지, 번역 버튼이 없는지 확인합니다.
4. **소스 확인**: 외부 통신 주소는 `index.html` 의 번역 함수 두 곳(`api.mymemory.translated.net`, `translation.googleapis.com`)뿐이며, 차단 코드는 `airgap.js` 에 있습니다.

## 8. 아직 갖추지 않은 것 (도입 전 필요)

| 항목 | 현재 상태 | 필요한 조치 |
|---|---|---|
| 안드로이드 서명 | **테스트용(디버그) 키**로 서명 | 정식 배포용 서명 키 발급·보관, 스토어 배포 시 Play 앱 서명 |
| 윈도우 코드 서명 | **서명 없음** — 실행 시 Windows SmartScreen 경고가 뜸 | 코드 서명 인증서(OV/EV)로 exe·설치 파일 서명 |
| 인증 | 없음 | 기관 요구에 따라 GS 인증, 보안 기능 확인 등 검토 (기관별로 요건이 다르므로 확인 필요) |
| 오픈소스 고지 | 앱 안에 없음 | 라이선스 고지 화면/파일 추가 |
| 망분리판 `INTERNET` 권한 | 선언되어 있음 (앱 안에서 차단) | 필요 시 망분리판 빌드에서 권한 자체를 제거하는 방안 검토 (동작 확인 필요) |
| 번역 API 키 저장 | 앱 저장소에 평문 저장 | 기관 배포 시 번역은 기관 내부 번역 서버로 돌리고 키를 앱에 두지 않는 방식 권장 |
| 실제 기기 검증 | 브라우저 자동 테스트 위주, 실제 윈도우 PC·여러 안드로이드 기기 검증은 아직 | 도입 전 대상 기관 PC·단말에서 시험 |
