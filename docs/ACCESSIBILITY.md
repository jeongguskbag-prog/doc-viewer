# 문서 통합 뷰어 — 접근성 자체 점검 결과 (v2.9)

> 기준: **한국형 웹 콘텐츠 접근성 지침(KWCAG) 2.2** · **WCAG 2.1 AA**
> 대상: Android 앱(일반판·망분리판), Windows 앱(일반판·망분리판). 네 가지 모두 같은 화면 코드를 씁니다.
> 성격: 개발사 **자체 점검**입니다. 공인 인증기관의 인증서를 받은 것은 아닙니다. 인증 심사를 받기 전에 미리 점검하고 고친 기록입니다.

## 1. 점검 방법

| 방법 | 내용 |
|------|------|
| 자동 검사 | axe-core 4.14(국제 표준 접근성 검사 엔진)로 WCAG 2.0/2.1 A·AA 규칙 전체를 검사했습니다. 밝은 화면·어두운 화면·고대비(밝게/어둡게)에서, 시작 화면·워드·엑셀·PDF·압축 파일·내보내기·설정·앱 정보·바코드 창을 각각 열어 검사했습니다. |
| 키보드 검사 | 마우스 없이 Tab·Enter·Space·방향키만으로 파일 열기, 문서 목록 이동, 엑셀 셀 이동·칸 크기 조절, 시트 탭 바꾸기가 되는지 자동 테스트로 확인했습니다. |
| 확대 검사 | 화면 글자 200%에서 화면이 넘치거나 잘리지 않는지 확인했습니다. |

**결과: 자동 검사 위반 0건** (개선 전에는 3종류: 색 대비 부족, 엑셀 시트 탭 역할 누락 등)

## 3. 저시력·고령 사용자를 위한 설정 (설정 → ♿ 접근성)

- **화면 글자 크기 100~200%**: 글자뿐 아니라 단추와 간격도 함께 커집니다. 앱을 다시 켜도 유지됩니다.
- **고대비 모드**: 흰 바탕에 검은 글자, 또는 검은 바탕에 흰/노란 글자로 바꿉니다. 테마(밝게/어둡게)와 함께 쓸 수 있습니다.
- **휴대폰 글꼴 크기 반영(Android)**: 휴대폰 [설정 → 글꼴 크기]가 앱 글자에도 적용됩니다.
- **테마 기억**: 밝게/어둡게 선택을 기억합니다.
- **동작 줄이기**: 기기 설정을 따라 움직이는 효과를 끕니다.

## 4. 남은 과제 (정직하게 적음)

| 항목 | 내용 | 계획 |
|------|------|------|
| 실제 화면 읽기 프로그램 확인 | 자동 검사와 구조 점검은 마쳤습니다. 아직 **TalkBack(Android)·센스리더·NVDA(Windows)** 로 사람이 직접 들어 보지 않았습니다. | 납품 전 실기기 점검(시각장애 당사자 사용성 평가 권장) |

| 공식 인증 | 이 문서는 자체 점검 결과입니다. | 필요하면 공인 인증기관의 앱 접근성 인증 신청 |
